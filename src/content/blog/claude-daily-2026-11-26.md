프로젝트마다 "분석해줘"로 시작해서 찾은 문제를 고치고 배포한 날. 저녁엔 Claude 작업 환경도 손봤다.

## 오늘 한 일

### dict
- 분석 결과에서 나온 문제를 고쳤다: 없어진 오답 항목이 랜덤 퀴즈·오답 목록에 남던 버그, 옛 캐시가 안 지워지던 서비스워커 문제
- OCR 워커에 허용 안 된 출처 차단과 IP별 요청 제한을 넣고, 클릭재킹 방지 헤더를 추가해 배포했다
- 한국어 음성은 가장 자연스러운 목소리를 고르게 하고, 읽기 속도 기본값을 1.0배로 바꿨다
- GitHub 저장소에 연결하고 올렸다

### train-app / train-proxy
- 오프라인 저장, 오류 문구, 막차 안내를 개선했다
- 환승 경로를 '지금 이후' 출발만 골라 보내게 하고, 같은 역 최소 환승 시간을 10분에서 1분으로 줄였다
- PR(코드 변경을 합치기 전에 검토받는 요청)을 처음 만들어 보고, master에 합치면 Cloudflare Pages로 자동 배포되게 설정했다

### Claude 환경 세팅
- 목표를 "Claude를 똑똑하게 쓰는 환경 만들기"로 잡고 계획부터 세웠다
- 웹 디자인 가이드라인·React 모범사례 스킬, Cloudflare 플러그인, serena를 설치했다
- 여러 프로젝트(festival-map, my-blog 등)에 CLAUDE.md를 추가해 상태를 정리했다
- 로블록스용 Rojo 템플릿과 테스트 게임을 만들어 실행 방법을 확인했다

## 막혔던 것 / 배운 것
- 로블록스 Studio가 프록시 서버 때문에 안 켜지는 것 같았다
- PR이 뭔지, 머지 후 자동 배포가 어떻게 돌아가는지 처음 익혔다
