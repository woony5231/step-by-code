오늘은 "내 블로그 만들기"라는 한 줄로 시작했다. 블로그 서비스를 쓸지 직접 만들지부터 정하고, 저녁쯤에는 내 PC에 블로그 프로젝트가 생겼다.

## 오늘 한 일

1. **방향 정하기**: 직접 개발 / 개발·기술 기록용 / 요구사항 문서부터
2. **요구사항 정의서 작성**: 기능 14개를 상·중·하로 나누고, 1차 오픈은 '상' 8개만 하기로 했다.
3. **결정한 것들**
    - 블로그 이름: 차근차근 코딩
    - 기술 스택: Astro + Cloudflare Pages
    - 댓글: 2차로 미루기
    - 오픈 목표: 12/31
4. **화면 시안**: PC 홈·글 상세, 모바일 홈·글 상세 4장
5. **카테고리**: 클로드 일일기록, 개발기록, 오답노트, 공부노트, 개발환경·도구
6. **프로젝트 생성**: `npm create astro`가 프록시 때문에 실패해서, npm으로 직접 설치하고 나머지 파일은 Claude가 작성했다.

## 오늘 배운 것

- 블로그에 DB가 꼭 필요한 건 아니다. 글은 마크다운 파일, 댓글은 GitHub Discussions, 검색은 빌드할 때 만드는 색인 파일로 해결된다.
- 프록시 환경에서는 npm이 잘 돼도 다른 도구는 안 될 수 있다. (오답노트에 따로 정리)
