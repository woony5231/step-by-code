오늘은 "내 블로그 만들기"라는 한 줄로 시작했다. 블로그 서비스를 쓸지 직접 만들지부터 정하고, 저녁에는 블로그가 실제 인터넷 주소로 열렸다.

## 오늘 한 일

1. **방향 정하기**: 직접 개발 / 개발·기술 기록용 / 요구사항 문서부터
2. **요구사항 정의서 작성**: 기능 14개를 상·중·하로 나누고, 1차 오픈은 '상' 8개만 하기로 했다.
3. **결정한 것들**
    - 블로그 이름: 차근차근 코딩
    - 기술 스택: Astro + Cloudflare Pages
    - 댓글: 2차로 미루기
    - 오픈 목표: 12/31
4. **화면 시안**: PC 홈·글 상세, 모바일 홈·글 상세 4장
5. **카테고리**: 클로드 일일기록, 개발기록, 오답노트, 공부노트, 개발환경·도구
6. **프로젝트 생성**: `npm create astro`가 프록시 때문에 실패해서, npm으로 직접 설치하고 나머지 파일은 Claude가 작성했다.
7. **GitHub 업로드**: 저장소 `step-by-code`를 만들고 첫 push.
8. **첫 배포**: Cloudflare Pages에 연결해서 [chagun.pages.dev](https://chagun.pages.dev)로 공개. 이후로는 push만 하면 1~2분 뒤 자동으로 반영된다.

## 오늘 배운 것

- 블로그에 DB가 꼭 필요한 건 아니다. 글은 마크다운 파일, 댓글은 GitHub Discussions, 검색은 빌드할 때 만드는 색인 파일로 해결된다.
- 프록시 환경에서는 npm이 잘 돼도 다른 도구는 안 될 수 있다. ([오답노트에 따로 정리](/blog/create-astro-proxy-error/))
- Cloudflare Pages 프로젝트 이름이 이미 쓰이고 있으면 주소 뒤에 임의의 글자(`-7dd`)가 붙는다.
