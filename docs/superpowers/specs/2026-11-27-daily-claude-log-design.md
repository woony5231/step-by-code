# 클로드 일일기록 자동 초안 — 설계

## 왜
매일 Claude와 어떤 개발을 했는지 나중에 확인하려고. 주 독자는 나 자신이고, 괜찮은 날만 골라 블로그에 공개한다.

## 목표 / 하지 않을 것
- 목표: 작업한 날마다 "프로젝트별로 한 일"을 짧게 요약한 초안 글이 자동으로 생긴다.
- 하지 않음: 자동 공개, 자동 커밋·푸시. 대화 내용을 길게 옮겨 적기.
- 실패로 볼 것: 비밀키·이메일·개인정보·회사 업무 세부가 글에 들어가는 것. 작업이 없는 날 빈 글이 생기는 것.

## 방법 (고려한 것)
1. **Claude 예약 작업** ← 선택. 매일 이 PC에서 Claude가 커밋과 대화 기록을 읽고 요약해 초안을 쓴다. 커밋 없는 작업까지 담기고 읽기 좋다. 매일 사용량이 조금 들고, 앱이 켜져 있어야 한다(꺼져 있었으면 다음에 앱을 열 때 실행됨).
2. 스크립트 + Windows 작업 스케줄러. 사용량 0이지만 커밋 메시지 나열이라 요약이 아니고, 커밋 없는 작업이 빠진다.
3. 블로그 밖 개인 폴더에만 기록 / 자동 공개 — 사용자가 "초안(B)"을 골라서 제외.

## 정한 것
- **언제**: 매일 23:30 (앱 예약 작업, cron `30 23 * * *`).
- **어느 날짜를 쓰나**: 마지막 일일기록 초안·글의 날짜 다음 날부터 오늘까지, 작업이 있는 날마다 한 편씩. (앱이 꺼져 있다가 다음 날 실행돼도 빠지는 날이 없게)
- **재료**
  - `C:\dev` 아래 git 저장소(한 단계 아래, `roblox\<게임>`은 두 단계)의 그날 커밋. `_archive`는 제외.
  - `C:\Users\ksm\.claude\projects\*\*.jsonl` 중 그날 바뀐 대화 기록. 사용자 메시지와 마무리 요약 위주로만 훑는다.
- **글 파일**: `src/content/blog/claude-daily-YYYY-MM-DD.md`
- **머리말**: 기존 글 형식 그대로. `title: "클로드 일일기록 YYYY.MM.DD: <그날 한 줄 요약>"`, `category: "클로드 일일기록"`, `tags`: 그날 작업한 프로젝트 이름, `pubDate`: 그날 23:30(+09:00), `draft: true`.
- **본문**: `## 오늘 한 일`(프로젝트별 소제목 + 2~5줄 목록), `## 막혔던 것 / 배운 것`(있을 때만). 반말 기록체, 기존 일일기록 #1 말투.
- **커밋하지 않음**: 저장소가 공개라 초안도 GitHub에 올리면 보인다. 파일만 만들어 두고, 사용자가 "공개해줘" 하면 그때 `draft: false`로 바꾸고 커밋·푸시한다.
- **완료 알림**: 실행이 끝나면 이 세션으로 알림.

## 빼야 할 것 (지시문에 명시)
- 비밀키, 토큰, 비밀번호, 이메일, 전화번호, 개인 경로의 사용자 이름, 회사·기관 내부 정보.
- 작업이 없는 날은 파일을 만들지 않는다.

## 구현 (만들면서 정한 것)
- 재료 모으기는 스크립트 `scripts/daily-log-collect.mjs <날짜>`가 한다. 커밋(`git log --all`)과 대화 기록의 사용자 요청(세션당 15개, 150자까지)만 뽑아 화면에 출력하고, 작업이 없으면 `NO_WORK`. Claude가 대화 기록 원본을 직접 읽지 않아 사용량이 적다.
- 예약 작업: 앱의 `daily-claude-log` (지시문: `C:\Users\ksm\.claude\scheduled-tasks\daily-claude-log\SKILL.md`). 최대 7일 전까지만 거슬러 쓴다. 23:00 전에 실행되면 오늘은 빼고 어제까지만 쓴다.
